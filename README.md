# Banking-DataAnalysis-Project
Banking DataAnalysis project to analyse issues related to transactions and customers
data containd 3 xlsx files 

 Imported all tables.
* Cleaned and validated the data.
* Handled missing values and duplicates.
* Build relationships between tables.
* Created a proper data model.
* Created a Date Table .

 Phase 2 – Analysis:
Performed a complete analysis of:

-Customer Analysis:
Understand customer growth, customer activity, customer behavior, and identify patterns that may indicate inactive or at-risk customers.

-Account Analysis
Analyze account balances, account types, account activity, and compare customer account usage across different segments.

-Transaction Analysis:
Analyze transaction trends, transaction behavior, account activity levels, and identify unusual patterns that may require attention.

- Loan Analysis:
Study loan distribution, loan performance, customer borrowing behavior, and future loan maturity trends.

- Card Analysis:
Analyze card issuance patterns, card type usage, and card lifecycle performance.

- Customer Support Analysis:
Analyze support requests, issue categories, resolution performance, and customer service trends.
